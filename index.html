Controls

Keyboard & Mouse

  • WASD or arrows — Move
  • Shift — Sprint / Surface Swim
  • Space — Jump / Breaststroke
  • C / Alt — Dodge roll / Parry window
  • F / Left-Click — Light Attack combo
  • R / Right-Click — Heavy Overhead Attack
  • Q / V — Target Lock-on
  • E / Enter — Interact / Continue dialogue
  • 1–4 — Dialogue choices
  • J / Tab — Journal & Equipment · M — Map
  • P — Photo mode · Esc — Pause menu
  • 8 / 9 — Teleport to Beast / Colossus Boss
  • F3 — Performance QA · F8 — Vista shot

Gamepad (Tactile Haptics)

  • Left stick — Move · Right stick — Free camera look
  • A — Interact / Jump / Dialogue continue
  • B — Dodge roll / Evade shockwave
  • X — Light Attack combo
  • Y — Heavy Attack
  • LB / L3 — Sprint
  • R3 — Lock-on target
  • LT / RT — Camera zoom in / out
  • Back — Journal & Equipment · Start — Pause
  • Dual-Rumble Haptics enabled on strikes, parries, & boss shockwaves
Photo mode Drag to frame · Enter save · P exit
